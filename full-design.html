面向化学时间约束的 Agentic Robot：完整研究方案

版本：2026-10-11，接续 MATTERIX 与 Auto-Engineering 的两轮来源审计。**这是一份完整方法设计，案例和训练算法尚未形成新的实验结果。** 原始来源、已完成组件测量、候选实现和需要独立验证的结论分别标注。Paper A 和历史 ICML 主 PDF 本轮不修改。
工作题目：**Learning Recoverable Robot Behavior under Chemical Time Contracts**。中文：**化学时间约束下可恢复机器人行为的学习**。工程系统可称“Chemical Auto-Engineering”；论文题目优先突出可检验机制，暂不把 Robot RSI 当成已经实现的能力。

1. 我们要讲的故事

化学操作既有空间目标，也有过程目标。把容器送到正确位置只是执行的一部分：液体是否在事件之后及时加入，停止动作是否真正终止了规定的物理过程，以及此前的等待是否已经改变了产物，都可能决定实验是否有效。
这里有两个不同的“完成”。机器人发出关阀或关闭加热命令，是控制层事件；最后一次液体转移、样品温度跌出某一区间或独立化学测量达到终点，是过程层事件。二者之间存在执行延迟、液体残流、热惯性和测量不确定性。一个视觉上合理的最终状态，可能对应有效实验，也可能对应已经错过窗口的实验。
普通恢复循环通常尝试让机器人重新完成动作。化学过程提出更严格的问题：**这次恢复是否还能让原实验有效？** 对仍在窗口内的失误，可以重新抓取、调整姿态或切换已有技能；如果不可逆的时间要求已经被违反，后来把东西摆好不能改写原实验。换一批材料重新开始可以产生新经验，但原尝试必须保留失败记录与成本。
因此，研究中心是：
> 能否让 agentic Real–Sim–Real 系统生成经过独立验证、保留时间与失败历史的恢复经验，并把这些经验吸收到一个多任务策略中，使它在新情境下选择及时行动、有效恢复、必要观察或安全终止？
这条故事有三个待检验机制：
1. **经验生成**：系统能否定位造成任务—时间联合失败的真正瓶颈，而不是只增加成功演示？ 2. **经验组织**：能否区分原任务内有效恢复、原任务已经失败后的处置，以及独立新尝试？ 3. **经验吸收**：改善能否在移除在线专家、固定外部工程栈后，保留在一个共享策略中？
工程平台负责让这三个机制可执行。论文贡献需要由实验支持，不能用“四个 harness＋多个训练阶段”的架构图代替。

我们提出四个优势假设，分别允许被反例推翻：
- 相比只有定时器或低延迟执行的控制，保留真实事件参照和过程响应可以减少“命令准时、物理效果迟到”的错误。 - 相比普通失败重试，保留不可逆历史和恢复时长可以减少无效重试，同时增加仍可挽救的原尝试。 - 相比只模仿成功轨迹或离线专家轨迹，学生状态中的有效恢复经验可以改善部署时的状态覆盖。 - 相比冻结策略外接记忆，吸收经过验证的多任务经验可能带来清空上下文后仍保留的收益。
这些优势不预设成立。若已校准的固定控制器足够，我们应把该任务用作负对照；若 matched DAgger 足够，就不把分布蒸馏作为必需创新。

3. 像参考案例一样：从一张实验台到完整闭环

以下五个案例是**拟议任务设计**，不是已经完成的机器人演示。“5秒”来自作者提出的问题，只用于说明一种任务合同；真实化学操作的窗口、材料、温度、浓度和产品要求由具体协议与先导计量确定，不能从示例反推化学规律。

案例一：先让机器人、相机和过程设备说同一种语言

输入是一套选定的机械臂、夹爪、相机和设备接口，以及工作台对象与任务定义。第一目标是建立明确的动作单位、坐标系、相机帧身份、控制节奏和设备状态。
系统首先调用已有抓取、避碰规划和设备操作技能，在无反应或已定义的低风险组件任务中验证接口。预检记录“命令生成—发送—设备接受—动作开始—可观察物理效果”，并将各时钟的对齐误差写入收据。动作单位、控制频率、相机交付或末端停止不一致时，先修复接口，不能把这类错误塞给策略训练。
本案例产出进入工程工件账本 K：机器人描述、标定、动作适配器、计时链路、设备响应模型和测试。它回答“平台现在能可靠调用什么”。无需新训练就解决的问题，应保留为模块化组合基线。

案例二：可见事件后5秒内完成一次指定操作

假设某任务要求：指定事件 e_ref 出现后5秒内，指定操作的**物理效果** e_done 必须发生。e_ref 可以是协议认可的可观测过程事件；e_done 可以是测量到的转移结束或其他明确的终点。相机里的颜色只能在校准支持其事件意义时作为参照，不能默认等于化学终点。
初始固定方案：事件检测器＋定时器＋校准动作响应＋短程规划。它应首先运行，给出该问题是否真的需要学习的判断。
如果失败，系统区分四类原因：参照事件检测迟到、策略决策迟到、机械执行迟到、独立终点记录不足。对第一类，修复或更换感知并测量交付延迟；对第二类，缩短决策路径或调整动作块；对第三类，校准动作持续时间并提前准备；对第四类，增加计量，不把未知当成动作失败的奖励。
接着增加任务相关变化：参照事件出现时刻改变、物体角色或目标容器变化、短时遮挡、动作过程中容器移动。不能只靠固定等待时间解决的条件，才进入学生训练。
这里形成第一种重要经验：在事件尚未发生时做准备，事件发生后立即执行，失误后只选择仍有时间完成的恢复。相同的最终姿态不代表这些策略等价。

案例三：规定时间结束加热，但关闭电源不是终点

先明确任务究竟要求停止什么：停止设备供热、使样品离开加热区、停止某个温度区间的暴露，还是达到独立化学终点。四种合同不同，不用同一个“关机”标签混算。
若合同只要求在指定时刻关闭设备，校准定时器可能已经足够。这是必须保留的负对照。
若合同针对样品过程，则需要测量热惯性、样品温度轨迹及操作响应。系统先拟合或辨识够用的过程模型，再比较定时器、预测控制和学习策略。仿真只在已验证的过程范围内提供训练，不把数字孪生的内部温度或反应进度直接给视觉学生。
失败经验也分层保存：因接口迟到而未关机，进入工程诊断；关机准时但过程过冲，进入模型与控制诊断；抓取转移失败导致暴露过长，可能产生可恢复与不可恢复的学生状态。若原暴露合同已经违反，后来冷却不改写原结果；冷却只能作为失败后的处置动作。

案例四：多个反应、一个机器人，时间窗口相互竞争

难度增加到两个或更多任务共享机器人或设备：每个任务有各自事件参照、目标窗口、操作耗时和前置依赖。此时“每个动作单独能做”不意味着组合后能按时完成。
固定调度器和预测控制是首要对照。系统应支持机器人运动与设备等待并发，并根据真实时间轴计算，不把并行动作的时长重复相加，也不让化学过程在 agent 思考时暂停。
agent 可在不可逆步骤之前预摆放、预抓取或请求补充观测；也可以选择先完成更接近截止时间的必要操作。若输入任务在规定资源下本来不可行，规划前可识别的不启动，与执行中才发现的失败分别报告。不能从成功率分母悄悄删除困难任务。
这里生成“决策级”经验：动作顺序、设备等待期间的资源使用、何时值得额外观察，以及失败后是否继续占用机器人。这是 option-level RL 的候选瓶颈，比直接让在线 RL 探索低层化学动作更清楚。

案例五：有失误时，选择恢复、终止或新尝试

考虑抓取滑落、遮挡、异常残流或设备响应改变。agent 先记录发现时间、当前已发生的事件、观察新鲜度和剩余时间，再查询可用恢复技能及其在当前条件下的时长支持。
若存在仍可能满足合同的恢复路径，执行短动作并持续监测；若缺少足够信息，可选择一个耗时可承受的观察动作；若已确定原合同失效，执行规定的安全处置并结束该尝试。换新批次时创建新 attempt_id，而非把原计时器归零后继续算成功。
学生在这些状态上 rollout。教师只给其支持范围内的动作或技能标签，对不支持状态明确弃权。系统记录 teacher proposal、实际执行动作、harness 接管及独立结果。教师的建议本身不构成成功轨迹。
最后比较三种“越做越好”：K 让接入和工程诊断更快；M 让冻结策略在后续尝试利用反馈；θ 让清空 M、移除专家后的学生仍更强。三者分别计量，不能用第二次更快部署证明权重学习。

4. 系统结构：四套工具、一条物理执行链、一个独立判定面

每个工具返回结构化结果、适用范围和版本，不只返回自然语言“成功”。第一版采用有限、可审计的操作库；能力不足可以提出新代码或模型候选，经隔离测试后升级版本，不能在正在进行的反应中改写设备适配器。

4.1 两种运行速度

慢速 agent 负责协议解释、实验选择、跨层诊断和构建路线；快速 actor 负责已经定义的技能选择和短动作执行。正在运行的化学过程不等待 LLM 返回。若 agent 在任务中调用工具，调用的实际延迟和反馈到达时间进入公共历史。
作者原路线中的 GPT-6 Astra 保留在任务级 agent / data engine 的位置，用于调用这些工具、生成实验假设和分析证据；低层动作由已验证的控制器与学习策略执行。实际采集时固定并记录 agent 的模型版本、工具、提示与调用预算，不从模型名称推断机器人控制能力。
运行时 contract monitor 提供公开观测下的状态估计和候选限制；独立 adjudicator 在锁定判定规范下给最终结果。二者可以用不同传感器与权限。训练可使用已释放的事后结果，部署只能使用该 track 明确开放的在线信息。

4.2 三类时间必须分清

1. **物理过程时间**：反应、液体流动、热暴露实际向前推进的时间。 2. **消息与执行时间**：曝光/采集、送达、推理、发送、接受和实际效果的时刻。 3. **训练与工程成本**：回放、回标、训练、诊断、材料和人工。
物理时间上的并发按区间并集处理。仿真快进或暂停可以帮助离线开发，但正式延迟实验需声明 process-time 模型；主机 CPU 的耗时不会自动等于仿真中继续反应的时间。
公共计时 track 与原有 no-clock track 分开定义。同一个 track 中所有方法的时钟、帧时间、控制日志和设备读数权限一致。增加时钟信息后不能仍称原无时钟任务上的同条件提升。

5. 数学定义：任务、合同、信息与不可逆历史

任务表示为 w=(G,O,N,C)：G 是目标和依赖图，O 是对象及角色，N 是对象/设备数量，C 是过程与时间合同集合。每个合同给出参照事件 r_i、必要效果事件 e_i、允许窗口 [L_i,U_i]、测量规则和违反后的处置。
用 τ_i 表示真实参照发生时刻，T_i 表示效果时刻，Y 表示独立化学/任务终点。已完全测量的一次尝试，其联合结果为
\[ Z=\mathbf 1\{Y=1\}\prod_i \mathbf 1\{e_i\text{ occurred and }L_i\le T_i-\tau_i\le U_i\}. \]
化学终点与时间终点分别报告；主指标是联合结果。每个判定保存 TRUE、FALSE 或 UNKNOWN：任一必要条件有可靠 FALSE 时联合为 FALSE；全部 TRUE 时才为 TRUE；其余为 UNKNOWN。UNKNOWN 不是负奖励的同义词，更不是可以从评估中剔除的样本。
在物理时刻 t，学生输入为
\[ \chi_t=(h_t^{pub},\,w,\,\hat q_t,\,M_{j-1}), \]
h_t^{pub} 包含截止该时刻真正送达的公共观测与执行反馈；\hat q_t 是这些信息推导的合同状态估计；M 是此前允许保留的经验。隐藏反应进度、未来帧、真实物理参数和独立判定传感器不进入部署输入。训练标签与部署特征分别存储。
每个公共事件记录至少有事件身份、对象、估计时刻区间、交付时刻、来源、置信/校准信息以及证据引用。晚到的事件记录可以更新“何时发生”的估计，但不能假装 actor 当时已经知道它。
**不可逆历史约束。** 对一个已锁定的原尝试，只要某必要合同被独立证据确定违反，后续动作不能把该违反改成满足。终点处置和新尝试可以改变后续状态，不能改变这个事实。这是判定定义的直接性质，不是新的学习定理或真实世界安全保证。

6. 核心方法：用时间支持约束恢复经验

6.1 运行时状态是估计，不是私有 oracle

合同估计 \hat q_t 保存已观测前置条件、活动窗口、未确定事件、观察年龄、正在执行的动作和不可逆风险。它可以是显式 token，不要求构造完整化学 belief model。
对于一个未满足的合同，公共参照区间是 [τ^-,τ^+]，公共当前时间估计是 [t^-,t^+]；候选恢复路径 ρ 的预计总耗时为 [d^-_ρ,d^+_ρ]。总耗时应包括路径中尚需的观察、决策、运动和设备效果，不只包括手臂轨迹。
其相对完成时间支持区间为
\[ I_\rho=[t^-+d^-_\rho-\tau^+,\; t^++d^+_\rho-\tau^-]. \]
- 若 I_ρ 包含在 [L,U] 内，且前置条件、资源、后续依赖和候选技能适用范围通过检查，标为“在校准支持下预计可行”。 - 若两区间相交但不包含，标为“时间结果未确定”，可考虑低成本观察或更稳的路径。 - 若无交集，标为“预计不能通过这条路径满足合同”。
这只是选路估计。真正的时间满足由独立执行记录判定。区间覆盖需要在实际选择分布上检查；多条件联合、分布漂移和主动挑选困难状态都可能使原校准失效。
单个动作准时也不代表整条任务可行。恢复路径要检验所有尚未满足的必要合同与依赖。第一版只在有限 option 图上枚举支持路径，不声称求解任意化学系统的全局 viability kernel。

6.2 必须给“多看一眼”和“终止”合法位置

候选 option 包含执行技能、补充观察、有效恢复、规定的安全终止。观察的价值取决于能否在增加信息后仍按时完成；不能无成本查询专家或等传感器。终止可以是正确的风险处置，但不会被算成完成了原化学任务。
共用保护 harness 对所有方法执行相同设备限制。其接管动作、次数和耗时单独报告。若保护层完成了关键停止，结果可反映系统表现，但不能无标注地归因给 actor。

6.3 经验不是一个“通过/丢弃”开关

一条经历 e 包含任务、公共轨迹、实际动作、独立判定、失败向量、恢复/终止记录、教师来源、版本和成本。它有多种消费资格：
| 消费者 | 可用材料 | 不可偷偷做的事 | |---|---|---| | 行为模仿 | 有效演示、独立支持的恢复片段、适用终止技能 | 把失败动作作为普通正例；把教师提案写成执行成功 | | 价值学习 | 有可信转移和已判定回报的成功/失败/恢复 | 将测量缺失一律置0；把新批次接到旧尝试之后继续 bootstrap | | 故障诊断 | 成功、失败、未知、接口异常、否决假设 | 只保留有利结果；未知等同算法无能 | | 历史适应 | 当时允许释放的反馈与经历 | 把事后私有标签提前放进上下文 | | 独立评估 | 所有预声明任务和已启动尝试 | 只统计被训练准入接受的轨迹 |
UNKNOWN 终局的可信动作片段可用于已定义的局部监督，不能未经处理用于终局价值。已确认原任务失效后的安全处置，归入“处置”，而非“成功恢复”。终止/重置技能与主要化学成功分别计分。

6.4 两个账本，三种改进

K 保存工程工件：接口、标定、控制配置、感知模块、twin、技能、训练配方及修复知识。每个工件有依赖、版本、测试范围、适用条件和失效条件；hash 只证明身份，不证明行为。
D 保存经历：原 attempt_id、batch_id、不可逆事件、原尝试判定和新尝试链接。外部标签延迟到达时追加记录，不重写过去 actor 可见内容。M 是从 D 派生的允许记忆视图。
K 变好是平台复用；冻结所有参数后 M 变好是上下文适应；固定 K/感知/保护层并清空 M 后 θ 更好，才支持 actor 吸收。更换感知权重也属于系统改进，但不能混入“同一 actor 学会时间恢复”的证据。

7. 策略与训练：选择一条可实施主线

7.1 第一版的策略表示

先训练一个**共享、历史条件、语言/合同条件的 visuomotor diffusion policy**，而非直接声称已经有通用大规模 VLA。图像编码器、任务/对象 token、合同估计 token 与有限交互历史编码进入共享时序模块。
输出两部分：离散 option/设备操作选择，以及当前运动 option 内的短末端动作块。机械动作采用明确单位的末端增量与夹爪状态，通过预检过的适配器转换；设备操作采用有类型的指令和确认，不把“关加热器”编码成任意连续向量。不同机器人迁移仍须检验可达性、控制映射与支持范围。
另设辅助头预测相关动作的物理耗时分布，以及候选结果 TRUE/FALSE/UNKNOWN 的分类。标签来自对应训练 split 的实际执行与独立测量，缺失 mask 保留。模型预测不替代独立判定。
未执行候选没有真实耗时或结果标签，不能拿教师猜测直接填表。可通过独立分支仿真收集候选结果，但必须计入预算并标明来源。未到达效果事件就终止的执行，其完成时间为删失数据；先导阶段可采用可信完成样本的监督与单独删失标记，覆盖评估必须包含这些样本，不能将“终止耗时”误作“成功效果耗时”。
实际层数、尺寸、历史长度、动作块长度、采样步数和损失权重在可运行后端的 pilot 后冻结；初版不通过增加模型规模解决所有失败。
动作块有明确的已提交前缀与可改写后缀。接近事件窗口、出现新失败或观察变旧时重新决策；提交长度由相同的执行器与候选持续时间支持确定，不能把整段不可中断轨迹交出去后指望最后一帧补救。RTC适配若启用，对我们与兼容基线使用相同实现；分开测量策略计算、排队与实际效果延迟。

7.2 DP：先得到可执行的行为先验

对已准入的动作块 A、公共条件 χ、扩散级别 n 和高斯噪声 ε，采用标准去噪监督：
\[ \mathcal L_{\mathrm{BC}}= \mathbb E\|\epsilon- \epsilon_\theta(\sqrt{\bar\alpha_n}A+ \sqrt{1-\bar\alpha_n}\epsilon,n,\chi)\|^2. \]
这部分继承扩散模仿方法，不是我们的原创。[Diffusion Policy 原始项目](https://diffusion-policy.cs.columbia.edu/)。
恢复片段应带失败类型、恢复开始时的剩余时间、动作结果和样本 mask。合同辅助目标包括已可靠测量的时长与结果，不使用未判定轨迹的伪成功标签。公共事件检测器与策略时间头的学习贡献需要分别消融。

7.3 学生状态回标：首先建立 matched DAgger

学生自主 rollout，保留它实际访问的状态及公共历史。任务专家在支持范围内给动作、option 或拒绝标签；新标签加入训练集，再评估新学生。标准硬标签数据聚合明确称 DAgger，不重新命名为分布 OPD。[DAgger 原始论文](https://proceedings.mlr.press/v15/ross11a.html)。
教师可以在仿真训练中具有额外状态权限，但必须记录并给同预算对照相同权限；最终学生不接收这些隐藏状态。覆盖外状态可以触发新增专家、采集或模型校准，不能默认教师永远正确。
回标通常在完成 rollout 后或隔离的仿真快照上进行。真实化学不能暂停等专家回标；如果在线调用专家参与控制，必须另设带实际调用延迟的对照，并记为在线教师系统。
快照须保留对象与设备过程状态、原始事件历史、正在执行的动作及可用公共信息，不能只恢复几何姿态。教师基于历史缺失的快照生成标签时，其标签不能视作原学生状态上的有效恢复监督。
重点采集两类相近但决策不同的状态：仍可恢复的失败，以及已没有有效原任务恢复的失败。采样可以强调边界状态，但必须给 matched baseline 同样的回标预算与状态分布；否则提升可能只来自采样更好。

7.4 Offline RL：仅在决策级瓶颈成立时引入

进入条件：已有先验能执行动作，但对顺序、观察、恢复选择存在可信的失败与替代结果；数据覆盖这些 option。先在 option 层使用 IQL 类价值学习，低层 DP 保持固定，再与共同数据上的模仿比较。IQL 的标准机制是已有方法。[IQL 原始论文](https://arxiv.org/abs/2110.06169)。
以 x 为完整公共条件 χ 的编码、o 为 option、d 为真实持续时间、r 为合同定义的回报、b_term 为终止标记。若目标就是联合成功率，有限尝试使用 γ(d)=1，不无意引入“越快越好”的额外目标：
\[ y=r+(1-b_{\rm term})\gamma(d)V_{\bar\eta}(x'),\qquad \mathcal L_Q=\mathbb E(Q_\eta(x,o)-y)^2. \]
若研究另行声明时长偏好，可用 γ(d)=exp(-λd)，但它会改变优化目标，应与主成功指标区别。时长已经通过合同与状态参与转移；不必为了公式好看额外折扣。
价值拟合用高 expectile 目标：
\[ \mathcal L_V=\mathbb E[ |\zeta-\mathbf1\{Q_{\bar\eta}(x,o)-V_\eta(x)<0\}| (Q_{\bar\eta}(x,o)-V_\eta(x))^2], \]
其中 ζ>1/2；option actor 对数据中的动作做截断优势加权监督：
\[ \mathcal L_{\rm option}= -\mathbb E[ \min(w_{\max},e^{(Q-V)/\beta}) \log p_\theta(o|x)]. \]
这是 SMDP 接口下的候选 IQL 使用方式，不是新的 IQL 理论。UNKNOWN 终局不产生假回报；在首次已确定必要合同违约时，任务价值转移终止，后续处置进入独立过程。终局回报与局部 shaping 的定义、mask 和 bootstrap 边界须在 pilot 后锁定。
如果上述数据无法支持价值学习，保留 DP＋DAgger 主线，不强行跑离线 RL。若要更新连续扩散 actor，必须另用有明确目标的优势加权去噪或适配算法，不能直接写不存在的精确动作 log-density。

7.5 Online RL：先仿真，再讨论真实部署反馈

进入条件：twin 的关键事件/响应误差已经量化，离线策略与保护规则可运行。先探索 option 调度与恢复选择，再决定是否需要低层运动精修。所有失败、终止、保护接管和预算耗尽计入实验。
首个方法验收不依赖真机在线化学 RL。真实部署先用于受控评价、计量和 twin 校准；在线真实探索的范围必须由可用设备、任务协议和已验证保护能力定义。不能从模拟保护规则推出物理安全。

7.6 多专家吸收：动作蒸馏与分布蒸馏分开

专家集合可以覆盖任务家族、恢复技能或不同设备响应；选择专家依据任务和公开条件，不读取私有终局。聚合时记录专家冲突、拒绝和支持范围。
第一版可靠实现是学生状态上的动作/option 监督。若教师与学生都提供兼容的扩散去噪接口，再增加一个明确的候选分布目标：
\[ \mathcal L_{\rm score}= \mathbb E_{\chi\sim d^{\pi_\theta},\; A_E\sim\pi_E(\cdot|\chi),n,\epsilon} \|\epsilon_\theta(A_E^n,n,\chi)- \operatorname{sg}[\epsilon_E(A_E^n,n,\chi)]\|^2. \]
教师在它自己的样本 A_E 的加噪版本上返回同坐标、同噪声日程的输出，学生条件来自自己的 occupancy；不支持的状态不生成此项标签。不同训练日程或输出参数化时先做一致的映射，否则不开启此项。
如果教师只能给动作样本，则使用动作样本去噪监督；若只能给硬动作，归入 DAgger 类监督。以上 score 目标不等于文本 OPD 的 token reverse-KL，亦不自带策略改进保证。[原始文本 OPD 说明](https://thinkingmachines.ai/blog/on-policy-distillation/)。
主实验比较离线专家模仿、matched DAgger、学生状态动作样本监督和满足接口条件的 score 蒸馏。对齐专家、回标状态、调用次数、样本量和计算预算。没有额外提升，就不把 OPD 写成论文核心。

7.7 多 episode 历史要教“学习”，不只教“识别任务”

构造真实顺序的交互历史：学生第一次行动、反馈何时到达、后续改变了什么。训练历史不能只拼接最终专家成功轨迹。任务中存在尚未公开的响应条件，策略通过自身行动和反馈更新记忆，再选择后续动作。
在固定 θ、感知、twin、K 和保护层条件下，比较真实历史、清空历史、打乱历史和无信息历史。报告每次尝试的成功率，而非只报告尝试越多必然增加的“至少成功一次”。清空上下文后保留的收益，另归入权重吸收。

8. 两层闭环的具体算法

8.1 单次尝试：执行—观察—有效恢复

输入：锁定协议 w、共享学生、预检工件、公共信息权限、统一保护层和资源预算。
1. 创建 attempt_id 与 batch_id，记录初始状态和物理时间链路。 2. 接收当前已经到达的观测；更新事件与合同估计，保存未确定项。 3. 生成执行、观察、恢复、终止候选；按支持范围和完整路径时间估计筛选。 4. 学生在允许候选中选 option 与短动作；监测实际执行和观察年龄。 5. 记录保护层接管。若原任务已确定失效，转处置，禁止通过 reset 改写历史。 6. 独立判定更新结果；按各消费者资格写入 D。终止后需新材料/重置时创建新尝试。
步骤3由同一实现提供给相应消融与强基线；不能把一个复杂规划器只给“我们的方法”，再声称都是权重贡献。

8.2 跨版本：如何选下一件值得做的工作

系统状态 z_k=(θ,ψ,φ,M,H,K,σ)：actor、感知、twin、记忆、runtime harness、工程工件及改进选择器。独立判定规范 V* 和主测试集合固定。
第一版 σ 采用可审计规则：
| 证据 | 下一步候选 | 必须先排除/验证 | |---|---|---| | 单位/坐标/控制节奏异常 | repair interface | 重放和独立预检确认原因 | | 事件交付迟到/追踪失败 | repair perception | 同一公开采集数据比较，记录新增延迟 | | 物理响应与twin差异 | calibrate twin | 用非最终测试的校准数据；比较冻结twin | | 现有技能可覆盖新任务 | compose | 依赖、可达性和时间条件共同通过 | | 学生进入教师/数据覆盖外 | collect / extend expert | 不把猜测标签当作验证 | | 覆盖足够但选择/动作失败 | train | 区分动作先验、决策瓶颈与模型问题 | | 原合同已失效 | terminate current attempt | 新采集/新批次单独计费计分 |
接着比较 fixed recipe 与根据失败证据选择下一项工作的 adaptive σ。初期不必再训练一个 meta-RL。若选择器只固定执行“DP→RL→蒸馏”，称自动化训练闭环；只有自适应选择本身在等预算下带来可靠收益，才讨论递归改进。
每次候选变更在隔离开发环境中产生、测试，再生成新版本；未通过的候选也计入总成本。跨版本比较固定分布 q_eval 上
\[ J_k=\mathbb E_{w\sim q_{\rm eval}} \left[\frac1K\sum_{j=1}^{K}Z_{k,j}\right]. \]
另设永不用于选择的最终测试集和旧任务保留集。跨版本自适应可能使选择指标过拟合，固定候选验证集并不足以自动保证最终泛化。

9. 数据与任务设计：从组件到完整化学结果

9.1 四层任务，不把组件成功写成化学成功

| 层级 | 回答什么 | 可用标签 | 能支持的结论 | |---|---|---|---| | 组件计时 | 命令/执行/观察链路是否正确？ | 曝光、接受、动作和物理代理 | 接口、延迟与组件控制 | | 过程任务 | 转移/热暴露/设备过程是否满足合同？ | 校准过的过程传感器 | 该过程条件下的任务—时间联合表现 | | 化学任务 | 材料与操作是否达到独立化学终点？ | 真实产物或协议认可的终点 | 完整化学任务表现 | | 组合与适应 | 新依赖/多任务/未知响应下能否保持？ | 同层级独立标签＋真实反馈 | 泛化、适应与吸收 |
先导仿真可采用明确命名的代理；不能把外观颜色、低流速阈值或设备关闭默认写成最终化学成功。

9.2 留出变量

训练/验证/测试至少按任务模板、过程实例或真实批次划分，不按同一视频的帧随机划分。保留状态空间变化与任务空间变化的独立表格：
- 状态：位置、光照、遮挡、观察交付与机械误差。 - 对象/角色：类别、数量、容器角色和被操作目标。 - 过程/设备：经过计量支持的响应差异、设备延迟和校准范围。 - 任务结构：目标组合、顺序、依赖图、共享资源与恢复条件。
训练失败库、twin校准、超参数选择和最终测试批次之间保留边界。新自然语言措辞不单独证明新任务学习。

9.3 反事实合同对

生成相近视觉场景但不同参照历史、截止窗口或依赖条件的任务对，检查策略能否改变预准备、动作时机或恢复选择。严格说明哪些变量被干预、哪些物理状态随之改变。
这不是默认“全RGB逐像素相同”：历史变化可能改变温度、流动、颜色等视觉因素，现有配对审计也有残差。只有通过完整观测审计的场景才作严格配对；其余采用匹配因素和非配对分析，不隐藏残差。

10. 实验：优先证明核心，不一次堆满十条路线

10.1 首批确认性问题

第一批先做四个主问题：**时间机制是否有用、有效恢复经验是否有用、是否进入共享策略、是否泛化到留出依赖/响应。** 工程复用和自适应研究选择在这些测量能成立后展开。
| 实验 | 主要问题 | 关键对照和锁定项 | 主要观测 | |---|---|---|---| | Q1 时间机制 | 事件与过程响应是否超出普通定时控制？ | 校准timer、预测控制/调度、固定模块、标准DP；统一感知与保护；适用时RTC | 联合TRUE/全队列、早/晚违约、UNKNOWN、实际观察/决策/执行延迟 | | Q2 恢复经验 | 时间支持与原尝试历史是否有贡献？ | 标准重试、相同数据DAgger、时间过滤、完整恢复标签；统一回标状态/次数 | 原尝试有效恢复、无效重试、终止、误拒绝、保护接管 | | Q3 吸收与适应 | 改善位于M还是θ？ | θ更新×M更新2×2；固定ψ/φ/H/K；移除在线专家 | 初次及第2/3/5/10次尝试；真实/打乱/清空历史；清空后保留 | | Q4 泛化 | 是否学会合同与依赖，而非固定时间？ | 单独留出响应、对象角色、图结构；固定预算/权限 | 留出联合结果、旧任务保留、失败向量、合同对决策变化 |
保持原10组候选实验的编号便于接续：E1验证与准入、E2失败/恢复数据、E3学生状态蒸馏、E4上下文适应、E5参数归因、E6任务空间、E7twin校准、E8跨版本选择、E9工程复用、E10构建路线。Q1–Q4明确它们的优先组合，不删改旧候选快照。

10.2 避免常见混淆

只成功数据与成功＋失败＋恢复数据的比较，应保持学习目标一致；换成另一种RL目标时另列算法效应。过滤正例改变的数据量要报告，并增加数据量或成本匹配对照。
对恢复模块做二乘二消融：**运行时限制开/关 × 学习中合同/恢复标签有/无**，共用基本保护。这样可以分清外置筛选器带来的收益与 actor 真正学到的决策。
执行等待与外部查询的延迟对所有方法按同一物理时间规则推进。人工帮助、在线教师、保护接管和模型调用完整计费。数据过滤不能过滤评估队列。
上下文实验报告 per-attempt SR 和改善趋势；“K次至少成功一次”是附加指标，因为独立重试也可产生 1-(1-p)^K 的累积成功率，不能据此证明学习。
工程复用比较固定任务序列的冷启动与经过验证的K；同时报告历史创建成本与本轮增量成本。相同机器人移到新任务更快，不自动证明跨机器人或策略权重学习。

10.3 样本、统计与计费

先用与确认性测试分离的 pilot 估计过程变异、测量缺失、算法随机性和可检测效应，再冻结批次数、任务数、训练随机种子、终止条件及资源预算。当前不凭空设定能够达到显著性的样本量。
完整报告 TRUE/FALSE/UNKNOWN 与原因。联合TRUE/所有预声明尝试为保守确认率，并给缺失率；必要时给把UNKNOWN全部视为成功或失败的界限。窗口宽度、参考测量误差和终点标准由协议决定，不能在看完结果后调到有利位置。
训练种子、真实批次和同一任务内多个尝试不是同一种独立重复。按任务/批次/种子层级报告区间；配对分析需要确有配对，重复帧不增加样本量。
资源采用向量预算：真实尝试、模拟物理时长、模型/教师调用、训练算力、工程时间、材料和人工；时间到验收报告截断时间与预算内完成比例，未完成者不删除。选择只用某一个成本作为主比较时，其他维度也必须披露。

12. 哪些理论能写，哪些需要实验

可以严谨写清：物理事件参照的半马尔可夫任务，三值判定，不可逆失败的保持，区间完成时间与合同包含关系，消费者特定准入，以及系统变化的归因定义。
如果所有相关区间确实在目标选择分布上有给定覆盖率，可以作标准联合误差界分析；独立性不是union bound的必要条件，但漂移与自适应选择会破坏未重新验证的覆盖。无需把这种基础分析包装成新安全定理。
不能仅从公式推导：“吸收一定提高成功率”“仿真安全保证真机安全”“有harness就是Robot RSI”“分布蒸馏优于DAgger”。这些都需要匹配实验，失败时应收窄结论。
更有价值的理论叙事是：当前图像对过程历史可能不充分；更长上下文只在含有可辨识反馈时有价值；恢复价值取决于必要事件尚可发生的支持范围；信息动作在有限过程时间内有真实成本。这个叙事连接 agent 的决策与 actor 的学习，而非另附一个没有作用的“agentic理论”章节。
