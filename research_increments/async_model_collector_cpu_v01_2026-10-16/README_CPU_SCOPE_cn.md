# 异步模型采集器：CPU 工程验证 v01（2026-10-16）

本包保留两次版本化常量 worker 接线检查，以及唯一一次实际的既有 P0 工程模型推理。P0 是此前同一已见 episode 上的小规模拟合模型；它不是语言条件 VLA，也不是新的机器人策略训练。此轮训练更新、原生模拟、GPU、真机、化学实验和合格 S/F/R 新增均为 0。

实际模型在独立子进程内做一次 16 步扩散采样，约 11.324489 ms；期间主进程留下两条状态观察的真实墙钟记录。143 条事件日志保存 121 次合成状态观察、一个输入前缀、一个推理 ticket 和八个动作槽。八行输出各自经当前守卫、持久化提交、CPU FIFO 和 RAW 回执；没有实际物理执行。

合成 tick 映射为 1 ms，但 tick 121 的实测墙钟累计约 607.141 ms。模型计算时间、接收时间和合成执行 tick 分别记录；这不是 1 kHz 控制率、实际截止时间精度或机器人安全性的验证。

`code/check_runtime_evidence.py` 可只读验证实际案例，不调用模型。原始模型驱动 `code/run_cpu_p0.py` 随包保留供检查，封存实验的唯一模型调用预算已用尽，不能把后续复现伪装成这次原始实验。环境为 Python 3.11、Torch 2.7.0+cu128 的 CPU 模式、NumPy；实际 checkpoint 和 177 条已见仿真 episode 的工程输入张量随包提供，不包括项目全部数据或任何主方法 VLA 权重。
