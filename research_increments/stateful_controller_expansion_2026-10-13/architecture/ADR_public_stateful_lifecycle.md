# ADR: Public stateful control with paid decision transactions

Accepted for the CPU implementation; native admission and formal32 remain separate gates.

The exact prospective_v2 SOURCE_ORIGIN copies the old interfaces, plant, referee and XML unchanged. Its public prior is I=.002, damping=.006, sensor period50ms, delivery lag100ms, dt10ms and decision charge20ms. A/C stop confirmation requires200ms; B's first actual angle2 crossing is the original anchor. The eight configurations have already been used for development and cannot become unseen holdout conditions. Strong public batch already solved them.

Candidate A would let each method own environment objects and callbacks. It offers fewer interfaces but allows hidden fault/state getters, inconsistent clocks and counters, and cancellation of accepted requests. Candidate B uses immutable public data, shared temporal facts and a cumulative request ledger, with strategy-specific lifecycle decisions. We choose B. Reviewed code and dataflow checks are the boundary; this is not a hostile-Python process sandbox.

The actor imports no plant, referee, private case, file reader or native getter. Contract accepts plain public dictionaries and stores canonical JSON. PublicFrame carries epoch, actual public now, Packet, ACK and accepted Reservation only. Unknown private fields, native wrappers, future information, epoch changes and conflicting receipt identities fail before action emission. Supply-chain evidence binds copied inputs and the actor import closure separately from any future environment driver.

The server's transaction ACK proves service, not physical stopping. A fresh power observation must have capture≥ACK+dt; a same-tick capture is pre-ACK. Power-off supports actuation evidence and a conditional forecast, not task completion. Completion needs observed stop onset and subsequent sampled confirmation. The first B anchor is immutable; compatible public-model interpolation refines that same event, with source packets and residual retained. No new cue, reset or private event can replace it.

Target A/C events follow the copied referee's first *confirmed* stop convention: a candidate that loses its hold before confirmation is retained as a failed candidate, then a later candidate may be checked against the original B. A confirmed first stop is retained. Missing expected public samples makes the relevant confirmation or maintenance evidence unresolved. This is sampled public verification; neither physical continuity nor true model-support coverage is claimed. B maintenance applies to its fixed6s interval, not every later packet in the episode. Its public motion, control profile (.06/.045 only) and sample coverage are separate predicates; a moving B at an unsupported .04 torque cannot pass that maintenance contract.

A B violation observed within the definite required inner interval yields FALSE. A violation observed only in the uncertain original-anchor tail band yields UNKNOWN, never a certain failure or a pass. The finite interval's later packets are diagnostics only. An unsupported A/C torque is reported as unsupported public control, not mislabeled as power-off. A/C time-window and graph booleans are conservative certificates: false means not certified, not a global impossibility proof.

Every strategy decision creates a transaction ready at now+20ms; physics continues. Previous committed intents may emit while a replacement is computing. At ready time the actor compares both its issued-request and public reservation footprints to the planning snapshot. A newly emitted request or changed calendar makes the replacement stale: retain actual requests and the prior program, log the paid discarded decision, and replan later. Initial batch may retry before its first program commits; it still locks one final program. Before emission a shared current-calendar guard blocks an unissued intention whose forecasted service/ACK no longer matches. Blocking does not charge an actual action; only a later paid strategy may replan that unissued intention. No emitted/accepted request can be retroactively removed or refunded. Only UNSENT or BLOCKED_UNSENT intents may be cancelled.

The action ledger charges an emitted request immediately, even before its public receipt/ACK. Later matching reservations do not charge twice. One token cannot bind two different server identities: retain the extra accepted identity as spent, reject the protocol and stop further emission for that epoch. Repeated identical identities are idempotent. Pre-existing accepted A/C reservations consume the same cumulative budget. All methods have A≤2, C≤2, total≤4; cancellation of an unissued intent frees planned capacity only. Candidate evaluations consume before evaluation, including resource rejections, with1000 per decision and10000 per epoch. Failed searches preserve the existing program and are not all-policy infeasibility proofs.

The strategies differ in executed lifecycle:

| Strategy | Committed behavior | Public feedback behavior |
|---|---|---|
| strong_batch | One complete strong joint program, including blind two-A redundancy | Verify receipts/effects and original-time contracts; never rewrite its program |
| guarded_hsm_retry | Joint-safe delayed feedback retry slot when feasible; otherwise the same strong blind fallback | Fresh A power-off can remove only an unissued redundancy; powered-after-service enables remaining retry. Missing feedback keeps blind fallback |
| event_resource_edf | Commit the complete remaining program using inherited deadlines | New public reservation, ACK/power branch or event evidence triggers unsent-only resource/dependency replanning |
| joint_interval_mpc | Optimize remaining conditional boxes and commit one request prefix | Recede on public changes and a configured100ms cadence; issued/accepted history stays fixed |

The HSM feedback slot is derived from50ms sampling+100ms lag+20ms paid decision, not a privileged fault flag. It is used only when the same joint effect/window/graph/resource checks admit it. The prior blind candidates remain available to all methods. EDF and MPC share remaining-state predictions and legal budgets; MPC uses a joint objective and prefix execution, EDF uses inherited deadline ordering and complete remaining execution.

The bounded search family is earliest-feasible-A prefix→C or C→A, with declared none/single-first-A-drop alternatives. It is not a global all-policy oracle. A model residual mismatch, unknown physical effect or persistent powered A after both requests remains unresolved; no unseen safety theorem is asserted. Shared known-model refinement means the original50ms B bracket is not an irreducible information lower bound.

CPU closed-loop scalar fixtures and recorded public packet replay validate software invariants. They are not native robot/chemistry experiments. Extra public-calendar and persistent-fault fixtures are explicitly software API stress, do not modify the canonical eight scenarios, and cannot establish agentic advantage. Any later native integration is capped at one predeclared development episode after independent review; formal32 is neither frozen nor run by this component.
