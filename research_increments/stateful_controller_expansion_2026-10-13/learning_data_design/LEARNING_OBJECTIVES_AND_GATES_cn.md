# 可验证经验接口与后续学习门槛

本组件只实现 CPU 元数据准入，不训练、不执行新物理轨迹、不复制帧，不把规则策略称作神经专家或 OPD。输入是已见的 20 条机器人旧实验和 8 条 CPU 开发 witness。原 4cal/16test 分母、事件、时钟和负结果全部保留。

数据边界有两张表。episode 表保留原身份、合同三值、目标范围及审计来源；causal candidate 表指向已有图像摘要和未来动作提交，再单独记录 FIFO 实际应用。学生输入为空。独立裁判位姿、接触、fault、终点和奖励可以成为受控标签，但不能出现在学生部署输入中。当前图像没有交付策略的时间，也没有实际图像条件策略，因此候选配对 UNKNOWN，不是可用 VLA 示范。8 条 CPU witness 的两次 A 是事先盲冗余，不是失败后反馈触发恢复。

学习的输入应是已到达的公共历史 h_t：语言合同、图像、合法 proprioception、公共传感器包、ACK、预约和允许的记忆。每项保留 capture、arrival、policy delivery、epoch、sequence 和来源。动作 a_t 是技能/目标和提交时刻；应用 u_t 由 FIFO/资源中间件产生，物理效果另由过程产生。不能把提交标签和裁判观察到的效果混成一个监督目标。新的动作 chunk 必须全部对应观察交付后的合法未来提交，并保留执行/未执行/尾部缺失 mask。

| 目标 | 准入材料与比较 | 当前门槛 |
|---|---|---|
| 完整 timed+hold DP | 新冻结可满足合同下，独立完整成功且观察→未来动作因果完整；同示范预算比较无时间 DP、公开时间/合同 DP、强规则 harness | 旧机器人完整成功 0/20；当前无合格行，不开始训练 |
| 部分机械行为先验 | 后续授权可将旧数据作为 LEGACY_SEEN_TRAIN，目标明确只学机械动作；首先补合法观察交付和因果标签 | 20 条只有机械目标的元数据资格，仍不具完整时间成功或当前训练准入 |
| Offline RL | 真实公共状态/历史、提交/应用、同 epoch 下一状态、独立终点/阶段标签与完整失败/恢复轨迹；匹配数据/计算的成功、失败、恢复消融 | 旧 UNKNOWN 保留证据 mask，不偷偷置零或从分母剔除；本轮不创建 RL transition 或 reward 张量 |
| Online RL | 新仿真任务和安全中间件先验收，冻结探索预算、原不可回滚事件与停止条件；同信息在线辨识+MPC 对照 | 未准入，无在线探索或策略更新 |
| 学生状态教师标签 | 学生实际 rollout 的访问状态，独立教师信息权限、查询数/耗时、标签时钟、拒绝与异常，保留学生失败 | 当前没有学生 rollout；旧规则轨迹合并只属离线模仿，不称 OPD |
| OPD / 权重吸收 | 同教师和查询预算比较离线教师模仿、规则 DAgger、学生状态标注和 OPD；多 episode context 另设清空与参数更新对照 | 0 teacher student-state labels、0 weights；需要真正多任务采集后再开启 |

目标标签分别是 mechanical、primary_timed_joint、strict_sampled_bilateral_hold 和 full_timed_and_hold。主计时 TRUE/FALSE/UNKNOWN 保留 8/2/6；严格保持 0/16。区间部分跨界是 UNKNOWN，不能说成已证实失败，也不能作为成功。RL 的未知奖励/终点应显式记录未识别，不因为训练接口需要单标量就制造确定真值；是否采用保守界、部分奖励或 censoring 是未来单独冻结的学习目标和消融。

旧 strict 与稳定释放可能有结构上的张开冲突，但尚无所有动作不可行的证明。下一合同需在采集前明确双侧夹持持续到“独立支撑建立”还是“复合稳定释放 onset”，并分别验证支撑交接、卸载、无夹指接触和稳定确认。若改变目标，发布新版本并保留旧 0/16，不回写旧标签。

当前不划随机 train/validation，也不把旧 test 悄悄挪入新的 heldout。未来用户授权旧数据训练时可单列 LEGACY_SEEN_TRAIN；保留其 original_role 并声明对训练后模型的旧 test 已非 untouched。新收集按 episode/物理实例/场景与任务生成器组前瞻划分，视觉 state-space 留出与图结构/依赖/目标组合 task-space 留出分开；不能把同一 rollout 的帧或三份合同拆到不同 split。CPU 八配置已经 seen，四控制器同配置测试只能是配对机制验证。

本设计对齐 root 的六场景计划：机械交接与释放、停转与恢复、限时加液、加热暴露、并行设备资源和多 episode 适应。每类先验证可达性、独立终点与同信息强基线。确定性强 batch/MPC 全解应如实平局；不能靠减少基线能力制造 agentic 必要性。继电器关闭不是热暴露终点，阀门 ACK 不是质量达到，仿真过程控制不是化学产率，规则/上下文调整不是权重吸收。

验收范围：可复验 schema、角色/事件身份、三值与目标准入、图像因果候选和输入拒绝边界。证据已有结果可见后才设计本接口，不声称本接口在旧实验前冻结。当前训练、权重、GPU、新原生 epochs、帧复制均为 0。
