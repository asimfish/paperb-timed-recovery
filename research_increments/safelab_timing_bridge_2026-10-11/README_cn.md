# SafeLab 只读桥接与物理计时恢复实验

本轮把完整 v3 方法设计接入 Paper B 网页，并实际完成 **216 条 MuJoCo 机械组件闭环轨迹、173,016 个原生状态样本与 3,672 张 RGB**。它验证计时、恢复选择和证据接口，**没有执行 Isaac Sim 机器人操作、VLA/DP/RL 训练或真实化学实验**。CT-C1 仍为 MAJOR_OPEN。

## 已恢复的基础设施

从 SafeLab 历史恢复了 933 条可见消息，范围为 seq 9865–10810 / id 16740383–16783152；最后一条是准备下一批源任务的工具调用。源任务当时仍在运行。用户随后明确授权独立 Paper B 工作目录推进；源代码、资源注册表、现有作业均只读。

SafeLab 延续批次验收增量为 53 条（Press 50、CabinetOpen 3），不是整个历史数据集总量。失败的 5090 批次及 Oven/Cabinet 未通过部分没有转成 Paper B 数据或结果。4090 SSH 的本地转发端口拒绝连接，当前主机也没有 canonical MANIFEST；没有提交 GPU 训练作业。

[只读源码接口收据](SAFELAB_INTERFACE_RECEIPT.json)绑定了采集器、episode manifest 和时间缓冲器的源码摘要，快照在 `safelab_source_snapshot/`。发现采集器的 `timestamp = frame_index / fps`，这可用于媒体/模仿数据布局，但不能替代物理事件、相机交付或控制器接受时间。桥接层对缺少独立事件计量的数据保留 UNKNOWN。声明 sidecar 也不能自动获得准入；仍需认证、时钟校准和独立事件审计。

## 实际实验

[开发协议](PROTOCOL.json)先于本轮执行保存；这是开发矩阵，不是预注册确认实验。复用固定摘要的 C5 机械转子 MJCF；物理参照是轴角跨过 2 rad，终点是流量代理（转速×0.05）低于 0.005 mL/s 并持续 0.2 s。终点时间取持续低流量段的起始跨越区间。它没有测量液滴或反应终点。

三种惯量、三种公开反馈延迟、两个时间窗口、三种指令故障组成 54 个参数案例。每个案例运行四种控制，共216轨迹；这些不是54种独立化学任务。所有组使用相同公共编码器/设备电源反馈、控制权限、标定与保护继电器；RGB只是实际渲染记录，未作为策略输入。故障与传输延迟是明确施加的开发条件，未称为测得的真实故障分布。

| 控制 | 全54例 T/F/U | 标定范围36例 T/F/U | 响应变化18例 T/F/U |
|---|---|---|---|
| 命令计时器 | 8 / 46 / 0 | 7 / 29 / 0 | 1 / 17 / 0 |
| 普通重试 | 12 / 41 / 1 | 11 / 24 / 1 | 1 / 17 / 0 |
| 校准调度器 | 17 / 36 / 1 | 16 / 19 / 1 | 1 / 17 / 0 |
| 时间过滤器 | 17 / 36 / 1 | 16 / 19 / 1 | 1 / 17 / 0 |

命令计时器的46例虽然 ACK 时间在窗口内，物理终点却不及时。校准调度器和时间过滤器的结果及恢复选择相同，**没有超越强基线的收益**。范围内多出的5例相对普通重试，不能归因给 VLA、权重吸收或新理论。

`PREDICTED_ELIGIBLE` 在本实验仅表示**成功执行该候选动作条件下**的时间区间预测，不是完整恢复准入。持续指令故障可能触发第二次恢复，增加未包含在第一次候选预测内的耗时；超出标定范围也会使预测失效。审计保留13个“预测 eligible、最后时间非 TRUE”的控制轨迹，其中三条来自同一范围内边界案例（UNKNOWN），其余来自范围外响应变化。它们不是13个独立失败任务。后续必须加入候选成功支持、依赖及剩余必需操作，不能凭持续时间包络认证恢复。

## 验收证据与局限

[独立审计](development_v1/AUDIT.json)从持久化编码器样本重算所有判定，不读取指令或故障标签来评分；核对54组控制分叉前的机械状态前缀和3672张图片摘要。不宣称全幅 RGB 严格配对。全部216例都进入分母，UNKNOWN保留。化学任务结果始终缺少独立终点：时间 FALSE 导致联合 FALSE，其余为 UNKNOWN，化学联合 TRUE 为0。

10项接口测试覆盖 ACK≠完成、跨时钟拒绝、区间跨越截止时间、预测与判定分离、原失败不可被后续成功覆盖、新尝试关联以及媒体时间不能取得物理准入。`red_state.txt`记录初始接口尚未实现的红态；不是既有系统缺陷复现。该账本为单进程组件，不是持久化、认证或并发生产账本。

模拟过程在显式传输/控制等待中持续积分。真实 CPU 推理与渲染耗时只记录，不推进模拟时间；本实验没有验证真实实时期限。标定是有限开发探针，没有统计或硬件覆盖保证。

## 重现

在本目录运行（新结果目录不得覆盖原结果）：

```bash
python3 -B -m unittest -v test_contracts
MUJOCO_GL=egl python3 -B run_recovery.py --out /tmp/paperb-recovery-new
python3 -B audit_recovery.py --data /tmp/paperb-recovery-new
python3 -s -B plot_results.py
```

使用已有 MuJoCo 3.3.7 / NumPy 2.2.6；绘图用 `-s` 的系统 Matplotlib 3.5.1 / NumPy 1.21.5，避免用户包 ABI 冲突，无全局安装。主实验资产与旧设计材料保持不变。
