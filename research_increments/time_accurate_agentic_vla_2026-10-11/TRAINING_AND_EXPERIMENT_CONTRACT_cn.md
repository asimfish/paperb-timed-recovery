# Time-Accurate Agentic VLA：训练与实验接口 V1

2026-10-11。这是下一阶段的实现规格，不是已执行训练或确认协议。主方案为 [RESEARCH_DESIGN_cn.md](paper_rewriting_output/RESEARCH_DESIGN_cn.md)。

## 最小方法与扩展顺序

先验证一个共享视觉—语言编码器、时间条件扩散动作头、离散计算决策头。主要比较是相同动作模型加校准模块化路由器 B；两者共享时钟、观测、timer、RTC、harness。只有在该比较显示开发 headroom 后，才实施更完整的专家训练和蒸馏。GPT、offline RL、online RL 和 OPD 都有独立保留条件，不因路线较长而自动成为贡献。

设公共编码为 `z=E(RGB, instruction, returned_history, clock, committed_prefix)`。动作头为 `πθ(a|z)`，计算头为 `μψ(m|z)`，m 包括 EXECUTE、OBSERVE、REASON、EXPERT、STOP。执行动作不可撤销的前缀另行记录。既有异步动作可在工具调用期间继续推进；不是每次调用都把机器人暂停。工具结果只有在真实返回后进入编码。

### S0：采集与公共数据

GPT agent 只使用公共协议和返回的信息提出工具/动作请求，harness 验证并执行。具体模型、快照、提示词和工具版本要在首次采集前冻结；本轮没有调用或采集。脚本对照获得相同任务分布、操作权限、采集时长和成本上限。失败、拒绝、取消和未返回调用都保存。

一条记录最少包含：

| 字段组 | 必须内容 |
|---|---|
| 过程身份 | protocol/task/instance/split、独立过程 ID、模型及工具版本、harness hash |
| 公共输入 | 图像引用和 capture 时间、语言任务、机器人/仪器公开状态、已经返回的结果 |
| 时间约束 | anchor 类型与已观测时刻、每项 [L,U]、单位、同步误差/未知标记、观测年龄 |
| 决策 | 路由动作 m、实际控制 a、已提交动作前缀、决策开始/结束、请求及返回时间 |
| 物理反馈 | command submit、physical start/end、stop end、后置条件及其记录来源 |
| 成本和终止 | 实际 Δ、工具/计算/环境成本、失败及取消类别、未返回状态、episode terminal |
| 标签来源 | 教师 ID、输入快照 hash、标签生成/返回时间、privileged 标记、查询成本 |

隐藏裁判输出单独存入 evaluator-only 记录，训练/策略输入白名单不得读取它。训练奖励可由裁判产生，但不能把评估时未来评分或私有过程参数送入策略。

### S1：时间条件 BC / DP

视觉、语言和时间字段进入同一编码。扩散 BC 使用实际执行动作序列：`L_BC=E[||ε−εθ(a_k,k,z)||²]`，或所选 flow 模型对应的速度目标。没有语言条件时只称 visuomotor DP。完成时间预测只作辅助损失，不能替代物理终点评分。

计算头先以经过记录的采集决策和开发集可核验备选分支监督初始化；若没有可靠路由标签，就先固定模块化 B，禁止将合成 oracle 标签说成真实 expert。联合和分别训练两头使用同一数据、容量、更新预算和损失权重搜索范围。

### S2：离线改进

任务专家使用有限时域 SMDP 转移 `(z,m,a,r,Δ,z′,terminal)`。无折扣主定义的 bootstrap 是 `r+1_nonterminal V(z′)`；截止和失效为终止。若选择连续时间折扣，固定 `exp(−βΔ)` 并同时用于所有对照。纯动作块的转移和信息调用的转移不能混用相同虚构时长。

先用 IQL 式 expectile V/Q 和优势加权去噪做开发适配：`A=Q−V`，`w=min(w_max,exp(A/T))`，`L_action=E[w ||ε−εθ||²]`。对具有实际路由标签的决策用同一优势定义作加权分类。T、expectile、w_max、终止和 reward 权重仅在开发划分选择。这里是待验证的扩散适配，不声称已有 IQL 收敛保证。

仅有动作示范而没有工具选择及回报覆盖时，不能据此可靠学习 REASON/OBSERVE 的 Q 值；应补充受预算限制的开发采集，或保留 B，而非对未访问调用做任意 Q 外推。Diffusion-QL 是候选替代路线，不与多种离线算法同时堆叠来掩盖归因。

### S3：在线任务专家

在过程随墙钟推进的仿真中更新任务专家。EXECUTE 分支使用 DPPO 式扩散链概率；路由分支使用 categorical probability。一次有效决策的 ratio 包含路由概率及该分支真正采样的动作因子。工具分支没有扩散动作时不能强加动作 ratio。辅助去噪链步骤与实际物理耗时分开记账，不能把虚拟采样步等同于化学时间。

共享任务回报同时训练两头；对照是分别训练的两头及同动作模型+B。更新停止规则、交互时间、样本量、实际 GPU/CPU/工具成本和延迟 profile 分别记录。DPPO 适配若不稳定，保留较简单的 BC/online 路线和负结果，不包装阶段必要性。

### S4：学生访问状态多专家 OPD

学生部署产生访问状态，按任务选择同信息专家。训练标签绑定学生输入快照和时钟；可用可重放状态复现专家标签，禁止把耗时后返回的历史动作标成当下即时动作。学生评估运行不使用训练标签。

动作蒸馏使用采样的专家动作及模型对应的去噪/速度目标；离散计算头使用专家路由分布或有出处的选择标签。一个学生 backbone、两个输出头和同一外部时钟/harness 部署。对照包括专家离线 BC、同覆盖恢复 BC、单教师学生状态蒸馏、任务 token 单模型、多专家 OPD；每项记录查询量、label age、active 参数和总预算。

## 实验门槛与确认前冻结项

| 开发门槛 | 必须回答 | 进入后续的条件 |
|---|---|---|
| G1 物理语义 | 加热/停止代理及限时转移两个家族；视觉和语言确实改变动作，physical end 独立计量 | 定时基线、可靠 timer/harness 与 B 均实际实现；没有 headroom 就记录饱和 |
| G2 路由价值 | 学习路由器 vs B；联合 vs 分别训练；免费连续视觉信息公平可用 | 不只超过 always-call 或 slack-only；有可解释的延迟/观察年龄分层效应 |
| G3 RL 价值 | BC、BC→offline、BC→online、BC→offline→online，数据和预算分别匹配 | 仅保留有独立开发作用的阶段 |
| G4 蒸馏价值 | 同覆盖、同模型容量、同教师成本下的学生表现和专家保留率 | 能排除恢复覆盖及更多标签解释 |
| G5 确认 | 完整配对过程队列、未见时限/延迟/组合、真实停止测量 | 模型、选择规则、主对照 B、任务/seed/数量、UNKNOWN 处理及统计规则全部冻结 |

确认主统计量是 `Δ_joint=mean(joint_success_candidate−joint_success_B)`，按独立过程/实例配对，保留失败和取消。三个训练 seed 是计划下限而非已完成事实；确认 episode 数和最小有意义差异需由开发方差确定，当前没有假定通过阈值。程序、视频、派生延迟的共同来源按 cluster 处理。
