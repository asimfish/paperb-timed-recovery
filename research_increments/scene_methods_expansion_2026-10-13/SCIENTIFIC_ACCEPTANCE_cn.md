# 下一阶段科学验收

本轮扩充的数学验证和机械任务图是组件证据。完整 Paper B 的状态仍是 MAJOR_OPEN；以下条件不能由合成格点或固定双转子代替。

## 三个贡献假设及证据门槛

1. **问题与基准：原始物理事件合同。** C5 的颜色事件与真实停流、C6 的实际运动起止、C13 的真实 A/B 加液须来自独立测量。采集时间、到达时间、派发时间、有效事件区间、确认时间和 clock ID 分开保存。至少一个持续过程在规划/推理等待及可恢复故障中继续演化，原始参照不可重置。新机械任务不得重命名为化学任务。
2. **机制：经过验证的恢复经验。** 在同观测、同数据预算下，比较成功轨迹、成功+失败、成功+失败+准入恢复。外置 harness 和共享策略分别消融；最终计分器始终相同。若只有规则补偿改善，只支持强调度组件，不支持学习贡献。
3. **吸收：学生分布上的经验进入一个策略。** 相同 teacher、标签量、模型容量、更新次数及原生步数，比较离线专家示范、学生状态监督回标和明确目标的多专家蒸馏。测试时清空上下文仍有收益才支持参数吸收；冻结权重但保留历史的收益属于上下文适应。监督聚合如属 DAgger 型方法，应保留该名称。

## 先执行的最小学习矩阵

优先完成共享 DP，而非预设 DP→offline RL→online RL→OPD 每级都有必要。统一视觉/本体输入和骨干，比较：不加时间；加合法公开时间；加捕获/查询执行时间；加过去合法历史；同一历史模型清空/打乱历史。无钟表 M1 是独立观测轨道，不能把公开时钟模型的结果搬过去。

在上述阶段出现留出收益之后，添加同预算学生状态回标。Offline RL 先比较 BC、过滤 BC 与保守价值/优势学习；online RL 先探索技能选择和派发，再评估是否需要运动精修。每个新增训练阶段都要回答一个独立假设，同时回归全部已验收任务。测试集不用于 agent 改配方、改验证器、挑 teacher 或选择恢复规则。

## 四种留出不能混用

| 留出 | 固定并登记的变化 | 结论边界 |
| --- | --- | --- |
| 状态条件 | 对象位置、质量/摩擦、视觉环境 | 插值和外推分别报告；帧不能跨 split |
| 时间条件 | 时长、容差、延迟分布 | 记录是否落在校准支持内；违反支持另报 |
| 任务图 | 新顺序、依赖、组合、设备容量 | 手写规则知道图不属于 learned zero-shot 泛化 |
| 过程漂移 | 同实例多回合中的动力学/延迟变化 | 首次和第2/3/5/10次均报，过去信息不能含未来标签 |

先冻结 generator、完整实例 ID、观测轨道与 collection/train/validation/test。环境 seed 与训练 seed 分开。计分按完整实例聚合，重复 episode 属于同一实例簇；拒绝、未知、超时、失败和安全停止都保留原分母。显著性与 bootstrap 以独立实例或实例簇为单位，小型确定性组件只列 raw counts。

## 主表必须保留的成本与失败

空间任务成功；时间 TRUE/FALSE/UNKNOWN；原始合同 joint；原锚点违例；另一个持续过程损伤；安全；准入覆盖；p50/p95/p99 捕获到执行/有效事件延迟；每次 agent 调用、teacher 标签数、原生步数、训练 GPU 时间和所有校准/诊断成本。多个合同作用于同一轨迹不能增加独立样本数。

实际推理时延实验要测量并校准物理进程和 host 单调时钟。当前 CPU MuJoCo 只推进登记的服务/交付时延，host 运算期间物理时钟暂停，因此不能支撑实时 agent 或真实超时主张。当前 FIFO 只延迟位置目标，不代表完整控制通信链路。
