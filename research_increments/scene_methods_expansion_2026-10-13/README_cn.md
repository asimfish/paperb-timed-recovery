# 场景与实验方法扩充：本轮证据

两组新组件已完成独立复算；FR3 的另一组校准/测试单列，不混入这两组结果。完整方法论文仍有学习、化学终点、真机与实时过程连续性等未完成验收。

## 扩充设计

研究设计覆盖8类任务及18个候选方法，逐项记录实际场景接口和物理准入缺口。故事、数学问题、近邻和后续学习实验见 [PROJECT_STORY_cn.md](research_design/PROJECT_STORY_cn.md)。停止加液、规定搅拌时长、加热及共享设备都需独立物理终点，不能用动作调用、炉门姿态或直接设置速度代替。已有物理时间策略与任务期限研究，因此本项目不再以“没人关注时间”作为创新。

## 数学调度验证：已执行

6,912个参数格条件＋256个固定seed合成条件＋4个边界例，共7,172条件。四旧方法比较28,688次；新候选另在全部7,172条件上验证。独立完整枚举检查299,040对有限派发格点，第三个LCM整数实现再次复核。

| --- | ---: | ---: | ---: |
| 名义补偿 | 409 | 975 | 0 |
| 显式FIFO补偿 | 788 | 981 | 0 |
| 独立校准中点 | 2,375 | 1,198 | 0 |
| 旧联合调度 | 2,545 | 1,198 | 3,429 |
| 修复后的精确候选 | 2,606 | 0 | 4,566 |

数学可行条件共2,606；不可行4,566。候选与完整枚举7,172/7,172一致。旧联合算法因独立中点预检提前抛异常，误拒61个可行条件，保留原失败版本；新候选属于独立源码版本，不覆盖已冻结FR3源。中点法另有994条件两项绝对窗口通过、事件间隔却失败。有限合同与区间模型的正确性不保证实际未知动力学安全；经验包络不是统计置信或真实支持保证。

这些均为CPU数学条件，新增原生episode和物理样本均为0，不构成机器人成功率。完整代码、roster、RAW输出和第三实现见 [数学归档](methods_component/cpu_contract_validation_7172.tar.gz)，[摘要](methods_component/summary.json)及[独立审计](independent_audits/PUBLIC_NUMERIC_AUDIT.json)。

## 四种机械任务图：已执行

同一接触自由的双转子MuJoCo模型，新增并行、A→B、B→A、A在B活跃时完成四个合同；3种同信息规则控制共享串行服务通道及全局继电器。动力学固定在公开校准支持内，故障固定none；不是原A/B/C、C5/C6/C13、化学反应或训练后策略。

| 每方法4个主合同 | joint TRUE / FALSE / UNKNOWN | 原参照违例episode | 必需B维护通过 |
| --- | --- | --- | --- |
| 独立窗口＋固定A/B顺序 | 0 / 4 / 0 | 4 / 4 | 0 / 1 |
| 图约束调度 | 1 / 3 / 0 | 3 / 4 | 1 / 1 |
| 图约束＋原参照保护 | 4 / 0 / 0 | 0 / 4 | 1 / 1 |

主12条轨迹全部A/B停止绝对窗口通过，但原参照、图依赖或B维护仍可使joint失败。主轨迹共有7个episode/8个事件违反原参照。B维护只有一个任务图要求，其余图的空真值不证明过程维持。

两条哨兵独立分母：可达合同witness通过；循环依赖正确拒绝派发，完整无操作物理轨迹合同记FALSE，正确拒绝另报。全部14受控轨迹为各自连续10s epoch，共14,014个样本；另1条全功率反事实参照积分1,001样本，预检100步单列。自身和第三审计均重积分原控制并重判事件，状态误差为0。重积分和导出不增加实验episode。

原参照是同MJCF和初态的全功率反事实位置过阈值区间，实际crossing必须保持同区间。本组件尚未验证外部已经发生的化学事件ledger恢复。停转事件须先观测运动，再有至少200ms采样跨度的低速段：21点；发生区间与确认时间分开。B维护也为逐样本谓词，没有采样间连续证明。

物理时钟只随登记的服务/交付时延推进；host计算期间此CPU fixture暂停。没有RGB、GPU、LLM调用或新策略权重，不能据此宣称模型等待时真实过程连续、学习适应或统计泛化。完整14条RAW、反事实积分、冻结源和接口见[物理归档](task_graph_component/native_task_graph_bundle.tar.gz)、[逐项结果](task_graph_component/MAIN_SUMMARY.json)及[第三审计](independent_audits/PUBLIC_TASK_GRAPH_AUDIT.json)。

## FR3另一个矩阵：进行中

冻结118源项，4条校准＋16条测试：质量/惯量、0/12tick位置目标FIFO、接触/稳定释放/两事件间隔，全部时间容差25ms。测试质量0.9/1.1位于校准0.8/1.2之间；固定场景、相关合同参数，仅支持配对插值组件，不支持多seed或因素独立归因。

首次启动因显存不足被拒，未产生episode。资源满足24GiB门槛后首校准完整执行，13,427条原技能指令、9份原生RGB-D快照、任务机械通过；其未调度时间诊断为EARLY，不能写成时间任务成功。其余校准按相同门槛执行；全部四校准通过独立RAW审计后才能拟合并冻结包络、开始测试。[发布时执行快照](NATIVE_A_PROGRESS.json)是进度记录，不是正式测试验收。不得降低资源门槛、抢占其他作业或覆盖已有失败。
