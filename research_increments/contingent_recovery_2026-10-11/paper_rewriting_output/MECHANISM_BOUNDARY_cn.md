# 完整失败分支支持与单设备任务的边界

这是组件机制分析，非新方法理论或化学安全保证。

在恢复决策时刻t，单次重试成功分支持续时间为d_retry + d_coast。重试失败分支还需要等待故障证据到达并启动备用停止：

```
D_success = d_retry + d_coast
D_failure = d_retry + d_fault_wait + d_feedback + d_relay + d_coast
```

完整候选时间支持取两个分支的区间并包络，再减去物理参照事件区间。若某分支没有执行/持续时间支持，不能从另一个分支的及时性推出整体可恢复。当前实现限定为一次重试→一次备用停止；没有模拟备用停止失败，故其支持是条件性的。当前speed=10的开发探针只提供低于该速度时的候选衰减上界，正的探针下界不应直接用于任意初始速度。

## 为什么直接备用停止更强？

本fixture是单一非负速度转子，正惯量I、正阻尼b，驱动u≥0；必要条件只有参照事件发生后在上截止时间内停止流量代理，没有备用停止的其他任务代价。参照事件在首次允许停止前发生，所有臂具有相同事件区间。

在该单自由度线性机械模型的隐式速度步进中，固定I、b、步长Δt时：

```
v_next = (I * v + Δt * u) / (I + Δt * b)
```

若两个控制从相同状态开始，且第一控制的驱动在每一步都不大于第二控制，则递推速度也不大于第二控制。直接备用停止在最早允许时刻设置驱动为零；因此其低流量跨越时刻不会晚于继续驱动等待重试的控制。固定相同参照和仅上截止时间的条件下，等待不能提高该组件的停止及时性。

这个比较限定在当前MJCF的无接触转子、相同目标、相同传感器与无代价可靠备用停止假设内。原生实测矩阵与该方向一致。它不推广到非线性化学终点、有下界持续要求、共享设备、动作损害或多操作依赖；也不把代理流量停止写成化学成功。

原生积分的额外复核覆盖三种机械设置、四种初速、三种驱动，共36个单步探针；最大绝对误差1.78e-15。三种设置、三种初速和两种零驱动延迟产生18组顺序比较，每组的立即停止跨阈时刻均不晚于延迟停止。这是模型范围的数值检验，不作为额外benchmark rollout或化学结果。详见[数值收据](../DYNAMICS_CHECK.json)。

## 对Paper B设计的约束

完整恢复路径应作为经验生成和准入的机制，但单独的停止任务不能证明学习收益。要检验学习/agentic价值，必须让选择改变多个必要条件或资源：比如全局停止可以及时结束A，却破坏B的必要持续操作；选择性停止更慢但保留B。强比较仍包括相同权限的确定性调度/MPC、模块策略、标准DP和匹配学生状态DAgger。

不为制造优势移除简单基线，也不在结果后修改已执行任务的判定规则。下一任务协议应单独冻结、保留全分母，再做运行时限制×学习目标和参数×上下文的归因。
